## Decision

Data is classified PUBLIC, INTERNAL, CONFIDENTIAL, RESTRICTED_FINANCIAL or RESTRICTED_IDENTITY. The classification determines egress, redaction, logging and consent requirements — in particular for the AI Gateway.
